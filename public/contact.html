Submit a request

Share this if you would like us to associate the request with your League profile.

What we need for medal ideas

  • Which type of athlete or effort you want to celebrate.
  • Any thresholds (distance, elevation, pace) we should verify.
  • Optional links or context that will help judge the idea.

What we need for race tracking

  • The exact date and starting location of the event.
  • The discipline (run, ride, marathon, etc.).
  • Expected distance and elevation so we can match activities.

What we need for climb segments

  • The Strava segment ID of the climb you would like highlighted.
  • Any local names or details that help us describe the climb.
  • Optional reasons why the climb is meaningful to the League.

We will verify the segment details with Strava before storing it.
